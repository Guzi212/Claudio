# 我的音乐品味

> 这是模板。想让 Claudio 更懂你，直接改这里，或复制成 `user/taste.local.md`（已被 git 忽略，推荐）。
> 文件不存在也能启动，但推荐会偏通用。

## 硬规则
- 原版优先，不要 live / DJ 版，除非场景明确需要。
- 同一歌手不要连续 3 首以上。
- 很在意音质，优先高音质 / 空间感版本。

## 收藏画像
- **语言**：华语为主，英文为辅。
- **节奏**：抒情慢歌和中速为主。
- **年代**：近十年为主。

## 歌手权重
**极高**：写 2–4 位你最常听的歌手
**高**：再写 4–8 位
**场景补充**：写你希望电台覆盖的风格线，例如 R&B、女声抒情、钢琴 / ambient

## 场景偏好
| 场景 | 推荐方向 |
|------|---------|
| 起床 07–09 | 轻盈 mid-tempo，不要一上来苦情 |
| 写代码 / 专注 | 少歌词优先：钢琴、ambient、轻电子、英文 acoustic |
| 雨天 / 阴天 | 慢一点、湿润一点、有回忆感 |
| 心情低落 | 忧郁但留温度，不要纯崩溃苦情 |
| 周末放空 | 轻快 groove、R&B、能跟着摆 |
| 睡前 / 夜深 | 钢琴 / ambient，控制 bass 和歌词侵入感 |

## 不喜欢
- 土嗨电音、喊麦感、强轰炸 bass。
- 无旋律的短视频热歌。
