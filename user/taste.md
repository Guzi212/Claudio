# 我的音乐品味

### 硬规则
- 原版优先，不要 live / DJ 版，除非场景明确需要或用户要求。
- 同一歌手不要连续 3 首以上（周杰伦/许嵩/汪苏泷尤其注意）。
- 很在意音质，优先高音质/空间感版本。

## 收藏画像（1686 首红心）
- **语言**：国语 70%、英语 17%、纯音乐 6%
- **节奏**：抒情慢(<80 BPM) 42%、中速 35%、快 18%
- **年代**：10s 54%、20s 29%、00s 12%

## 歌手权重
**极高**：周杰伦（80首）、许嵩（52首）、林俊杰（43首）、薛之谦（34首）
**高**：邓紫棋（21首）、汪苏泷/邓寓君（各16首）、张杰（15首）、蓝心羽/李荣浩（各12首）
**R&B/soul 线**：陶喆、王力宏、郭顶、李荣浩 — 增加 groove 和呼吸感
**女声抒情线**：孙燕姿、蔡健雅、梁静茹、徐佳莹、郁可唯、阿桑 — 清透克制会讲故事
**英文池**：OneRepublic（304次）、Taylor Swift（8首）、Maroon 5、Avril Lavigne、Troye Sivan、The Lumineers、Mina Okabe、Sasha Alex Sloan
**钢琴/ambient**：安涛（年度837次，最强夜深信号）、Marconi Union《Weightless》、岸部真明、久石让

## 场景偏好
| 场景 | 推荐方向 |
|------|---------|
| 起床 07-09 | 轻盈 mid-tempo，周杰伦/孙燕姿/英文 acoustic，不要一上来苦情 |
| 写代码/专注 | 少歌词优先：钢琴、ambient、轻电子、英文 acoustic；中文歌词会抢注意力 |
| 雨天/阴天 | 周杰伦、孙燕姿、蔡健雅、梁静茹、徐佳莹；慢一点湿润一点有回忆感 |
| 心情低落 | 忧郁但留温度：《路过人间》《遇见》风格，不要纯崩溃苦情 |
| 周末放空 | 陶喆/王力宏/Maroon 5 那种 groove R&B，轻快能摆 |
| 睡前/夜深 | 安涛、Weightless、钢琴/ambient；控制 bass 和歌词侵入感；晚间播放3514次是最高峰 |

## 近期强信号
- 年度歌手：周杰伦（5320分钟，前1%）；近期强推：《雨下一整晚》《不该》《一点点》
- 年度单曲：安涛《Serene Awakening》（837次），夜深/放空/专注场景最强 anchor
- 季节：春冬→安涛钢琴，夏→OneRepublic《Counting Stars》，秋→岸部真明《流れ行く云》

## 不喜欢
- DJ 歌曲（非明确要求不推）
- 土嗨电音、喊麦感、强轰炸 bass、短视频热歌、无旋律堆情绪
- 连续苦情中文歌（可以有但要有温度留有余地）

### 推歌时记住
- 节奏偏「抒情慢(<80)」(42%)，快歌谨慎穿插
- 国语是骨干（70%），跨语种穿插1-2首增加层次
- 写代码/专注优先少歌词；中文强叙事歌词只在用户明确想听、雨天、低落时提高权重
- 最近播放降权，除非同时出现在红心+收藏+近期循环里
- 推高频歌手时穿插英文 acoustic、轻电子、R&B 或女声抒情，避免单一怀旧榜单
