Claudio 是一款面向个人场景的 AI 私人电台播放器。选歌交给外部的 Grok Bot（Claudio主持人）：它读取用户的音乐偏好和日常节奏，通过 HTTP 接口把歌单和串场口播投给 Claudio；Claudio 负责酷狗音乐检索、直链和歌单写入，在 PWA 播放器中形成可听队列，并把播放历史和喜欢 / 跳过反馈回传给主持人。项目解决学习、工作、通勤等场景下“想听音乐但不知道放什么”的决策疲劳问题。亮点是主持人和播放器分离、接口带令牌与 Host 白名单、可本地部署，界面为宣纸水墨画风并按时辰换色，支持歌词、音量记忆、媒体键和全局热键 Ctrl+Alt+K。也可切换回内置模式，由 Claude 结合时间和天气直接选歌。
